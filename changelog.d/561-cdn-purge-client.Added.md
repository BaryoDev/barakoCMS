- **A CDN purge client and per-tenant settings for it.** `GET` and `PUT /api/tenant-settings/cdn-purge` set a tenant's provider (`none`, `cloudflare` or `fastly`), target id (zone or service id), token and an enabled flag, off by default. The token is encrypted and write only; reads say `tokenSet`. Cloudflare purges by tag in batches of 100 and Fastly by surrogate key in batches of 256. The default tenant reads `Delivery:CdnPurge` host configuration. `cdn-purge` is now a reserved settings section name. See `docs/cdn-purge.md`.
