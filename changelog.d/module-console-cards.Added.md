- **Modules can declare console cards.** `IBarakoModule.ConsoleCards` lists up to four small cards, each a title, a route the module serves and an optional button label. A card with a label gets a button that sends POST to the route to ask for a fresh card. `GET /api/modules` returns them as `cards` for an enabled module, and an empty list otherwise. A card with a bad id, title or route is dropped with a warning. The route returns a `ConsoleCardContent` and enforces its own permission. The field is additive, so the API contract number stays at 17.
