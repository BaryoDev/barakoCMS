- **A content type can declare a realtime topic.** Set `RealtimeTopic` on the type and a signed-in reader of the type can `Subscribe` to it on `/hubs/realtime` and read `GET /api/changes` for it. A branch scoped type notifies only the readers of the entry's branch. Notices and feed items carry ids and the lifecycle state, never field values. `GET /api/contents/{id}`, by-slug and the list now return `lifecycleState`.
