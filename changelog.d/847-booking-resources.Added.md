- **A Booking module.** New package `BarakoCMS.Booking` (in the Suite). A resource is a document with an IANA time zone, weekly opening hours, date exceptions and a slot length (or free-form). Bookings are ordinary content entries; a lifecycle hook refuses an overlap with another active booking of the same resource inside the write, under a per-resource lock. `GET /api/public/availability?resource=&from=&to=` returns free slots only, bounded by range and throttled per IP. Admin routes under `/api/booking/resources` need the `manage_booking_resources` capability. Module HTTP contract version 1. Holds, payment links and .ics files come later.
