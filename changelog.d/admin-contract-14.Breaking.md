- **The admin API contract moves from 13 to 14 and the delivery contract from 9 to 10.** An `X-Tenant` that names a tenant other than the owner of a verified request host now answers 403, where it used to be accepted. The check runs on every route, `/api/public/*` included, so both surfaces move. `X-Api-Contract-Version` and `apiContractVersion` in `GET /api/meta` report 14, and `X-Delivery-Contract-Version` and `deliveryContractVersion` report 10. barakoBrew 1.11.5 reads admin contracts 1 to 14, so upgrade it together with the API. barakoPress logs a warning on a delivery contract newer than it knows and keeps running.
- **Delivery API: a renderer on a tenant's verified custom domain must not send `X-Tenant` for another tenant.** This is a security fix (it closes a way to act as one tenant on another tenant's domain), so it ships in a minor under `docs/delivery-api.md`. What a consumer has to do: drop the `X-Tenant` header on requests to a verified custom domain, since the host already names the tenant, or send the header with the tenant that owns that domain. A request that names a different tenant answers 403.
