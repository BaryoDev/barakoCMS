- **A comment thread on any record.** The new `BarakoCMS.Comments` module adds `POST /api/comments`, `GET /api/comments?targetType=&targetId=` (paged) and `DELETE /api/comments/{id}`. A comment can be a reply to another on the same record. Reading or adding one needs read access to the record itself, so nobody sees a thread on an entry they cannot read. Content entries work out of the box, and another record type joins by registering an `ICommentTarget`. Comment text is stored and returned as text, never as HTML. Capabilities: `read_comments`, `post_comments`, `manage_comments`.
