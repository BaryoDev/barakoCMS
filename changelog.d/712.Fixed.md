- **The quickstart's backup container crash-looped once the folder was copied out of the
  repository.** `quickstart/docker-compose.yml` mounted `../scripts`, which only exists inside a
  checkout, so an operator following the README got a running API and no backups. The quickstart
  now ships `scripts/backup-cron.sh` itself, `scripts/check-quickstart-backup-script.sh` fails CI
  and preflight when that copy differs from the original, and a CI step copies the folder out twice
  and waits for each backup container to log a successful dump. The fixed `container_name` is gone,
  so two copies can run on one host.
