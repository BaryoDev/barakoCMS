- **Editing or deleting a redirect left the old answer in the cache.** It now clears at once. Redirect import rejects a from with a query, fragment or host, rejects a repeated from in one file, rejects a permanent value other than true, false, 301 or 302, and keeps the stored 301 or 302 when the permanent column is empty or absent. These are per-line entries in the `rejected` list of an unchanged 200 response, so the response shape and status are the same and the admin contract version is not moved.
