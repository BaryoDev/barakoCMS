- **Set `DB_APP_PASSWORD` before you upgrade.** `docker-compose.prod.yml` and `quickstart/docker-compose.yml` refuse to start without it, because the API now connects as the app role `DB_APP_USER` (default `barako_app`) instead of the database owner. Pick a random value that differs from `DB_PASSWORD`; the job that starts before the API creates the role and sets that password. With `docker-compose.secrets.yml`, add `secrets/db_app_password` and change `secrets/db_connection_string` to the app role's user and password. A deployment that sets `DATABASE_URL` must point it at the app role too.
