- **Workflow parameters named like credentials were hidden on read but stored in clear.** Only a
  parameter named exactly `Secret` was encrypted, while `Password`, `Token`, `ApiKey` and every
  other name the API redacts sat in plain text in the stored workflow. Every credential-named
  parameter is now encrypted with `ISecretProtector` on save, and the runner decrypts all of them
  except `Secret` before the action runs, so custom actions receive the same values as before.
  Workflows already stored are encrypted in place by a migration that runs when the API starts, on
  every partition, and leaves values that are already encrypted alone. A value still in clear, such
  as one copied onto a run queued before the upgrade, is passed to the action unchanged. One that
  will not decrypt fails the attempt permanently with a message naming the parameter. (#765)
