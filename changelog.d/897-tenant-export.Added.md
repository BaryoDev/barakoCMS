- **A tenant can be exported as one stream.** `GET /api/tenants/{handle}/export` (needs `manage_tenants`) returns every document that carries the tenant, plus the memberships, API keys, stations and audit entries keyed by its slug, as one JSON object per line ending in a `_summary` line. Connector secrets, mail provider settings and pending registrations are left out. Modules add their own data by implementing the new `ITenantDataContributor`. Import and erase come later.
