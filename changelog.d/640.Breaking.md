- **`POST /api/auth/login` answers 401 instead of 423 for a locked account.** That changes a status
  code, so `X-Api-Contract-Version` moves to 4. The barakoBrew console does not treat 423 specially,
  but it refuses to start against a contract version it does not speak, so it has to accept contract
  4 and be upgraded in lockstep with this release. A client that read 423 to show a lockout message
  now sees the ordinary invalid-credentials answer. See the Security entry for why. (#640)
