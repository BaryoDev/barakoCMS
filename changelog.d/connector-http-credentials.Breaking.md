- **Connectors send credentials only over https.** A connector with a bearer token, Basic auth, an API key header or OAuth2 client credentials no longer sends them over plain `http`, except to a host and port listed in `Webhooks:AllowedHosts`. Loopback is not exempt, since the address guard already refused an unlisted loopback address at connect. The probe, sends, fetches and the token request to `TokenUrl` are refused before any secret is read, and the result says to use an `https` URL. Connectors with `auth` set to `None` are unchanged. Before you upgrade, move each credentialed connector's `baseUrl` and `TokenUrl` to `https`, or list an internal receiver in `Webhooks:AllowedHosts`. A listed host may also resolve to a private address, so list only a receiver you run.
