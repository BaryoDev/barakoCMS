- **BarakoCMS.AI has a completion client other modules can call.** `ICompletionClient` takes a system block, a data block and a max length, and returns the text with the provider and model that ran. It is off until `Modules:AI:Completion:Enabled` is true, uses Ollama by default, and calls OpenAI or Anthropic only when `Completion:Provider` names it and its key is set; with no key there is no hosted call. The size caps and the timeout (`Completion:MaxInputChars`, `MaxOutputChars`, `TimeoutSeconds`) are enforced in the client, and a failure is a `CompletionException`, not an HTTP exception. Nothing calls it yet. The API still reports the module as `AI`; the package is `BarakoCMS.AI`. The README says what leaves the instance when a hosted key is set.
