- **The HealthChecks UI dashboard is gone from the image, and the image runs on `aspnet:10.0-noble-chiseled-extra`.** `AspNetCore.HealthChecks.UI`, `.UI.Client` and `.UI.InMemory.Storage` are no longer referenced, which also removes Entity Framework Core and the Roslyn assemblies they pulled in. `/health`, `/health/live` and `/health/ready` answer as before. `/health-ui` and `/health-ui-api` are not served any more. A deployment with `HealthChecksUI:Enabled` set logs one startup warning naming the setting; to get a dashboard back, host `AspNetCore.HealthChecks.UI` in your own application and point it at `/health`. The final image has no shell, so a container healthcheck that runs `curl` or `sh` inside it must move to a probe from outside (an HTTP probe in Kubernetes, or the database container's own check in compose). Admin contract is already at 10 for this release.
