- **Expressions, datasets and row loops in email templates.** A template can hold `{{= expression }}` with a `| format`, and a `Datasets` field names saved queries whose rows a `{{#each lines}}` loop repeats with `{{row.Qty}}` and `{{row.Product.Name}}`. `sum`, `count`, `avg`, `min`, `max`, `first`, `last` and `lookup` work on a dataset, so an invoice is built by configuration. Rows are read as the user the run acts as, in the template's tenant. A template loop fails past 200 rows, a reference loop stops at 50 with a note, and a result over 1 MB fails with a message. A value is encoded for where it lands and is never read as template text. A `Conditional` condition may also be an expression that reads `actions.N.Name`, and the old `{{x}} == y` form keeps its meaning. A stored template holding a literal `{{=` now evaluates, and `db-migrate --status` lists those. A Request action refuses the new forms until its own support lands.
