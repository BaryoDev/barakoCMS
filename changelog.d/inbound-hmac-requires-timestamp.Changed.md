- **Breaking: a plain HMAC inbound webhook now needs a timestamp header.** `InboundWebhookRequest` with the `Hmac` scheme and no `TimestampHeader` is refused as a bad signature, where it used to verify the body alone with no freshness check. The signed string is `{timestamp}.{body}` and the five minute window applies. A sender that cannot send a timestamp needs `AllowBodyOnlySignature = true` on the request, which keeps the old body-only check. Svix is unchanged. The first refusal is logged once with the fix.
