- **Each test host publishes to its own metrics registry.** Metric holders and counters (`WorkflowMetrics`, `JobMetrics`, `ApiKeyRefusals`, the auth mail drop count, the projection lag gauge) are no longer static and write to the host's own metric factory, which is prometheus-net's default registry in production, so a single production host shows the same series as before. `BarakoTestHost` and the repository's test fixture call the new `ServiceCollectionExtensions.UseIsolatedMetricsRegistry()`, which gives a host its own registry with its own runtime, process, event counter and meter collectors, stopped with the host; a test that builds a host itself can call it too. Removed public constructors (6.0.0 is a major): `AuthMailQueue(IServiceScopeFactory, ILogger<AuthMailQueue>)` and the `ScheduledContentService` constructors without an `IMetricFactory`. `AuthMailQueue` and `ScheduledContentService` now take a trailing `IMetricFactory`, so a host that builds them by hand passes its own factory.
