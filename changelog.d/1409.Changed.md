- **Each test host publishes to its own metrics registry.** Metric holders and counters (`WorkflowMetrics`, `JobMetrics`, `ApiKeyRefusals`, the auth mail drop count, the projection lag gauge) are no longer static and write to the host's own metric factory, which is prometheus-net's default registry in production, so a single production host shows the same series as before. `BarakoTestHost` and the repository's test fixture call the new `ServiceCollectionExtensions.UseIsolatedMetricsRegistry()`, which gives a host its own registry with its own runtime, process, event counter and meter collectors, stopped with the host; a test that builds a host itself can call it too. Public signatures: `AuthMailQueue` and `ScheduledContentService` each gain a constructor with a trailing `IMetricFactory` (the existing constructors stay and count to a registry nothing scrapes, so a host that builds them by hand loses their metrics on `/metrics`). `BarakoCMS.Testing` goes to 6.0.0 because hosts it builds no longer share the default registry.
