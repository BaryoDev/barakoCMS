- **A tenant domain is a claim that starts pending, and only a verified one routes.** Each domain a tenant lists has a `TenantDomain` row keyed by the host, so two tenants cannot claim one domain even when two writes race (the second gets 409). A domain added through the API is pending and routes nowhere: `by-host`, `tls-ask` and CORS answer for it as for an unknown host. The tenant response gains `domainStates` with the status and the DNS record to publish. Existing domains are copied in as verified by `migrations/5.5.0/1280-tenant-domains.sql`, which production must apply before the upgrade because it runs `CreateOnly`. A domain the seed file lists is verified.
