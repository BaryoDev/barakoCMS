- **The S3 storage tests ran against MinIO, which is archived and gets no security patches.**
  `S3FileStorageTests` now runs against SeaweedFS 4.46 (Apache-2.0), pinned by digest, and
  `Testcontainers.Minio` is gone. The Files.S3 README lists the S3-compatible stores that work and
  marks MinIO unmaintained. The docs no longer claim a self-hosted store applies the public-read ACL:
  only AWS does, on a bucket with ACLs enabled, so elsewhere set `UsePublicReadAcl` to `false` and
  make the bucket public.
