- **Service principals, capability scopes and read-only keys for API keys.** A key can act as a service principal in its tenant, so it keeps working when the person who made it leaves. A `cap:<capability>` scope reaches an endpoint gated on that capability, and a `bcms_ro_` key refuses every write. Platform, user, role, tenant and key management capabilities cannot be given to a key. See `docs/api-key-service-principals.md`.
