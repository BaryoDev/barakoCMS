- **A module can seed, read content and run a lifecycle hook without naming a Marten type.** `IBarakoModule.SeedAsync(IModuleSeedContext, CancellationToken)`, `IContentLifecycleHook.BeforeSaveAsync(IContentHookContext, CancellationToken)` and `IContentReader` (get, page, count, read all) are new, and `CapabilityDefaults.GrantAsync` takes the seed context. The Marten-typed members stay and are marked `[Obsolete]` with removal in 6.0.0. Both have defaults that call the older member, so a module written before this seeds and guards writes as it did. First-party modules seed through the new member. `BarakoCMS.Abstractions` 5.1.0.
