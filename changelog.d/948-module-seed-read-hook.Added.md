- **A module can seed, read content and run a lifecycle hook without naming a Marten type.** `IBarakoModule.SeedAsync(IModuleSeedContext, CancellationToken)`, `IContentLifecycleHook.BeforeSaveAsync(IContentHookContext, CancellationToken)` and `IContentReader` (get, page, count, read all) are new, and `CapabilityDefaults.GrantAsync` takes the seed context. The Marten-typed members `SeedAsync(IDocumentSession, ...)`, `OnBeforeSaveAsync`, `ContentLifecycleContext.Session` and `GrantAsync(IDocumentSession, ...)` stay and are marked `[Obsolete]` with removal in 6.0.0. The new members have defaults that call the older ones, so a module written before this seeds and guards writes as it did. First-party modules override the new member and keep their old `SeedAsync(IDocumentSession, ...)` override as an `[Obsolete]` wrapper, so a host on core 5.0.x that only calls the old member still seeds them. The reader sees the whole database the session points at, with no tenant filter, as a query on `Content` did. Four hooks (`JournalEntryHook`, `LedgerService`, `PageTreeHook`, and `ParentReferenceHook` with `ParentFields`) and the module template's Notes endpoint still use Marten, because they need the write session for locks or number allocation. `BarakoCMS.Abstractions` 5.2.0.
