- **A new module, BarakoCMS.CdnPurge, purges Cloudflare by cache tag.** Add the `CdnPurge` workflow action to a workflow that triggers on publish. It purges the entry tag, the type tag and the sitemap tag, built by `DeliveryCache.PurgeTags` so they match what delivery reads emitted, each starting with the run's tenant. Set `Modules:CdnPurge:ZoneId` and `Modules:CdnPurge:ApiToken`. A rejected purge fails the action on the run. `DeliveryCache.PurgeTags` is new and public. Fastly is not covered yet.
