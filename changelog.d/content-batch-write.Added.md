- **`POST /api/contents/batch` creates entries and runs lifecycle transitions in one transaction.** Send up to 100 steps, each `create` (with a client-made `id`) or `transition`. Every step faces the checks of the single create and the status change: permissions, write sensitivity, the create rule, save and transition rules, validation and hooks. The first refusal answers with the step as `steps[<index>]` and saves nothing. A transition may name an entry created earlier in the same request. A creator still needs `Lifecycle:AllowSelfTransition:<Transition>` to move on their own entry. `Idempotency-Key` applies as on any write.
