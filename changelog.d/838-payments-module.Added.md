- **`BarakoCMS.Payments`, a module for taking payment for an entry.** A content type is declared payable with `PUT /api/payments/payable/{contentType}` (amount field, currency, description, the paid and failed transitions). `POST /api/public/payments/checkout` takes an entry id and a provider name, reads the amount from the entry on the server, and returns the provider's hosted checkout URL; an amount in the request is ignored. `POST /api/payments/webhooks/{provider}` verifies the provider's signature, handles each provider event id once, and runs the paid transition as the `payments-webhook` system actor. Each try is a `PaymentAttempt`, Sensitive by default. Providers implement `IPaymentProvider`; none ships yet. Capability `manage_payments`, granted to Admin.
