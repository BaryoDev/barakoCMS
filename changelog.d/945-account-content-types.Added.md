- **A content type can be owned by an account.** `POST /api/accounts/{slug}/content-types` defines a type that every tenant in the account uses: it is listed in `GET /api/content-types` with `ownerAccountId`, and entries written in those tenants are validated against it while staying tenant scoped. A field added with `POST /api/accounts/{slug}/content-types/{name}/fields` applies to all of them. A tenant admin cannot change it, an account manager can, and a tenant outside the account does not see it. A tenant-local type of the same name is refused on create. New `AccountContentType` document. First slice of #945: workflows, lifecycles, roles and the field migration of #934 are not in it.
