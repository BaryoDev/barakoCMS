- **Optional signed one-click approvals.** With `Workflows:ActionLinks:Enabled` set to true (off by default, `Workflows:ActionLinks:ExpiryHours` defaults to 72), `{{links.action "Approve"}}` in an Email action resolves to a signed link for that transition, on that entry, for the user the email is addressed to. `GET /api/public/action-links/{token}` shows what confirming would do and changes nothing. `POST /api/public/action-links/{token}` (with optional `data` for the transition's fields) makes the move as that user, with their permission and row conditions checked at that moment, and spends the link. A link fails once spent, after expiry, when the entry has left the state it was issued in, or when the user may no longer make the move, and every failure answers 404. New `ActionLinkUse` document.
