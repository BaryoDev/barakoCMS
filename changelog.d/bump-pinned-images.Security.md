- **The compose files and Kubernetes manifests pin newer postgres, pgvector and caddy images.** Each stays on its tag line (postgres and pgvector on 16), so an existing data volume starts as before. The Kubernetes postgres and backup images are now pinned by digest like the compose files. Findings no newer image of those tags fixes yet (Go stdlib in the gosu helper, x/net in caddy, libxml2 in postgres) are accepted until 2026-12-20. An entry in `.github/vuln-allowlist.json` can now name the images it applies to, so an advisory accepted for one image still fails in another.
