- **Moving a connector's token URL to another origin now needs its client secret again.**
  `PUT /api/connectors/{slug}` answers 400 when `settings.TokenUrl` changes scheme, host or port, a
  `ClientSecret` is stored and the request neither enters it again nor clears it. It used to be
  accepted, when the setting meant nothing. This is the rule `baseUrl` already has, for the same
  reason: the editor cannot read the stored secret, and it would go to the new host. The refusal is
  part of contract 6, so `ApiContract.Version` does not move again (#574).
