- **A client had to write to find out whether a write would be accepted.** `POST /api/contents`,
  `PUT /api/contents/{id}`, `POST /api/content-types` and `POST /api/content-types/{name}/fields`
  take `"dryRun": true`: the write runs every check the real one runs and answers with `dryRun`
  and `changes` (each field it would set or change, with `from` and `to`), storing nothing. A write
  the real request would refuse is refused the same way. See `docs/dry-run.md`.
