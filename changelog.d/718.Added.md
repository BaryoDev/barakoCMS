- **Pages module.** `BarakoCMS.Pages` turns a content type into a page tree, configured under
  `Modules:Pages` (type and field names, `MaxDepth`, `ReservedSlugs`, `HomeSlug`, `MaxPages`), with
  defaults matching the `blog` blueprint's `page` type. A write is refused when the parent field
  points at the entry itself, closes a loop, nests past `MaxDepth`, or gives a top-level page a
  reserved slug. `GET /api/public/pages/navigation` returns the nested, ordered menu with absolute
  paths, `GET /api/public/pages/resolve?path=` returns the page at a path with breadcrumbs (404 on a
  miss), and `GET /api/pages/tree` returns every readable page, drafts included, for the console. The
  public bodies go through the public content projector, so only published, Public data is served,
  and each carries a `contract` integer. The module seeds nothing and stores no documents.
