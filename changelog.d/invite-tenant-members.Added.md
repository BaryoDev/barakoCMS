- **A member with the `invite_tenant_members` capability can invite people into a tenant with a role marked `Invitable`, and nothing else.** `POST /api/tenants/members/invite` grants only an invitable role of the tenant, never changes an active member, refuses a removed one, and refuses a profile value another active member holds. `GET /api/tenants/members/invite` lists the invitable roles. Admin holds the capability by default.
