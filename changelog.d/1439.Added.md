- **Configuration reference.** `docs/configuration.md` lists every configuration key core and the bundled modules read: the environment variable form, the default, the allowed range, and what a blank or malformed value does, including whether it fails at start or on the request that reads it. List keys say whether they take indexed entries (`ForwardedHeaders__KnownProxies__0`) or one comma-separated string (`CORS__AllowedOrigins`). `ConfigurationReferenceTests` scans the source and fails on a key read with no row, a row nothing reads, or a row removed from a run-time key list. No default changed: a blank or malformed limit keeps its default or refuses to start.
