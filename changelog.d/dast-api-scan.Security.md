- **A weekly ZAP scan of the running API.** The DAST workflow starts the production compose stack, scans it with ZAP anonymous and as a User-role account, and fails on a new High alert or a scan that could not run. The log is public, so it prints only counts per risk level; the reports stay in a folder the job deletes. `bash scripts/dast-scan.sh` runs it locally, and `security/zap/accepted.tsv` lists accepted alerts. See "Scanning the running API" in `docs/compliance-posture.md`.
