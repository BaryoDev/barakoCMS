- **The page tree did not say which fields it was built from.** A console moving a page wrote the
  default `ParentPage` and `NavigationOrder`, which a site whose type is `landing` with `MenuWeight`
  does not have. `GET /api/pages/tree` now carries `options`: the configured `contentType`,
  `parentField`, `showInNavigationField`, `orderField`, `titleField`, `maxDepth`, `reservedSlugs` and
  `homeSlug`. Signed in only; the public navigation and resolve bodies do not carry it. Additive, so
  the `contract` integer does not move.
