- **The legacy workflow engine read a data field named Status as the entry's status.** It now matches conditions the same way the run queue does, so a condition on `Status` always means the entry's lifecycle status (Draft, Published and so on). **Check before upgrading:** a workflow whose `Status` condition was meant for a data field named Status, on a content type that has one, stops matching after this release, and nothing reports it. Rename that field (for example to `Stage`) and change the condition to match.
