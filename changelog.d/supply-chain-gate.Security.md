- **Images and workflows are scanned for known vulnerabilities, and accepted advisories have an expiry.** CI builds `barako-cms` and `barako-cms-decaf` and scans them with Trivy (pinned, checksum verified), as it does the third-party images the compose files and manifests pin. The release scans each image before it is pushed, so a failing image is never published. A High or Critical finding with a fix fails the gate; one with no fix yet is reported. `.github/vuln-allowlist.json` is the one list of accepted advisories for NuGet and images, and an expired entry fails the gate. A nightly run repeats the NuGet check on master and scans the latest released images, and sends findings to code scanning. CI fails when a workflow uses an action not pinned by a full commit SHA, `ci.yml` and `release.yml` default to read-only permissions, CodeQL also analyses the workflow files, and Dependabot watches the Dockerfile and compose pins. Image signing is not part of this change.
