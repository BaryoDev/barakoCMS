- **A workflow fired for one content type, so purging a site's cache took one workflow per type.**
  A workflow can now name several types in `triggerContentTypes` and fires for each of them
  (#726). It fires for `triggerContentType` and every type in the list, so a workflow saved before
  the list existed keeps firing for its single type, with no migration. Saving one stores every type
  in the list and the first in `triggerContentType`, and `GET /api/workflows` returns both, with the
  list filled for older workflows too. A blank entry in the list is refused, and a transition
  trigger checks every listed type declares that transition. The change is additive, so
  `ApiContract.Version` does not move.
