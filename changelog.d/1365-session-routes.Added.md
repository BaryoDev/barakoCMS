- **List and end signed-in sessions.** `GET /api/me/sessions` lists the caller's live sessions with the current one marked, `DELETE /api/me/sessions/{id}` ends one, and `POST /api/me/sessions/revoke-others` ends the rest. A global SuperAdmin has `GET /api/users/{id}/sessions`, `DELETE /api/users/{id}/sessions/{sessionId}` and `DELETE /api/users/{id}/sessions` for any user. Every end writes `auth.session.revoked` with the actor, the user and the session id. Lists are paged and the routes use the `logout` rate limit. `ApiKey.LastUsedIp` is written with `LastUsedAt` and `GET /api/api-keys` returns it as `lastUsedIp`. New routes and an optional field, so the API contract version does not move.
