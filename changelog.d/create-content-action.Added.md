- **Workflow action `CreateContent` creates a numbered entry.** It goes through the same create path as `POST /api/contents`, so the type's save rules, validation, lifecycle hooks, numbering and initial state apply, and the entry keeps the run that made it in `SourceRunId` and the branch of the triggering entry. A retry of the same attempt reports the entry it already made instead of making a second. It runs as the system, so the caller's Create permission is not asked and fields above Public are dropped. The entry is always a draft, and the user who saves the workflow needs create rights on the type.
