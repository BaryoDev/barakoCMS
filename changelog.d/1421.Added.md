- **A Query workflow step.** A step reads entries with a saved query, as the user behind the event, and hands the first row's fields to later steps as `{{actions.N.Field}}`. Saved queries also gain a text form (`from student where Number = @data.StudentNo select Email limit 1`), parameters in filter values, system fields (`id`, `status`, `createdAt`, `updatedAt`) in select and order by, and one reference level in select. A field the user may not read fails the step by name. The run record keeps the row count, never a value or an entry id.
