- **A `choice` field type.** A field declares ordered `options`, each a stable `value` and a display
  `label`, and `multiple` for a list. An entry holding a value that is not an option is a 400 naming
  the accepted values, matched exactly, case included; a multiple choice takes a list with no repeats,
  and a required one with an empty list is missing. Options differing only in case are refused when
  the type is defined. `GET /api/content-types` returns the options in order, the OpenAPI document
  lists them as an enum, and a delivery or saved-query filter matches a choice by value, with `eq`
  and `ne` meaning "holds" for a list. New `PUT /api/content-types/{name}/fields/{field}/options`
  rewords labels and adds options without touching entries; removing an option entries still hold is
  a 409 with the count unless `force` is set. Additive, so `ApiContract.Version` does not move (#803).
