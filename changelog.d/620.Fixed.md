- **Semantic search read every embedding for a content type on every anonymous request.**
  `GET /api/public/{type}/semantic` loaded all stored vectors into memory before ranking them, then
  re-checked each hit with its own query. It now reads at most `SemanticSearchScanLimit` embeddings
  (default 1000, twice what one index run writes) and checks the hits in one query. When a type
  holds more than the limit, the response carries `"truncated": true`, because a better match may
  sit outside the rows that were ranked.
