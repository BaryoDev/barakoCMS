- **A field can be computed.** A field definition takes `computed`: `{ "fn": "hours", "args": ["TimeIn", "TimeOut"], "round": 2 }`. The functions are `add`, `subtract`, `multiply`, `divide`, `round`, `min`, `max`, `hours`, `days`, `duration` (minutes), `concat` and `coalesce`. The server works the value out inside every write (create, update, transition, workflow) and stores it, so it filters, sorts and delivers like any field. A write that sets a computed field gets a 400 naming it, unless it sends the stored value back. Saving a type refuses an unknown function, a missing input, a type that does not fit, a field that reads itself, a cycle, and a computed field more widely readable than its inputs. `POST /api/content-types/{name}/fields` takes `computed`. Rollups, backfilling existing entries and `if` come later.
