- **Rollup windows.** A rollup can count only a window of its entries with `where: { "createdAt": "thisMonth" }`, or a `date` or `datetime` field of the summed type in place of `createdAt`, and one of `today`, `last7Days`, `last30Days`, `thisMonth`, `lastMonth` or `thisYear`, in the site's time zone. A daily sweep recounts windowed headers as the calendar moves, and every rollup header on Mondays. An entry read now carries `rollupsAt`, when a recount last changed a rollup value on it. A new index on content type and created time serves `createdAt` windows, with a migration script and its rollback.
