- **The Portability module's HTTP contract moves from 1 to 2.** `GET /api/portability/export` answers 400 past `Portability:MaxImportRecords` records (default 5000), the same limit an import enforces, where it used to load every entry into memory and answer 200. The count is of stored entries, including any a bundle would later skip. This is a module contract move, so `ApiContract.Version` does not change. `GET /api/meta/describe` lists Portability at 2.
