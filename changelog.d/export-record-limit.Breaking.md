- **`GET /api/portability/export` now stops at the import limit.** It answers 400 past `Portability:MaxImportRecords` records (default 5000), where it used to load every entry into memory and answer 200. The count is of stored entries, including any a bundle would later skip. This is a Portability contract change, so `ApiContract.Version` does not move. The module publishes a contract number for the first time in this release, and `GET /api/meta/describe` lists it at 2.
