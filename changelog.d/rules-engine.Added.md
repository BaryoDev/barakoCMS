- **Content types can declare save and transition rules.** `ContentTypeDefinition.Rules` is a list of `RuleDefinition`. A rule runs on create and update (`When: Save`) or on a lifecycle transition (`When: Transition`). Its conditions must hold or the write is refused with 422 and an `errors` entry named `rules` carrying the rule's message. A passing rule can also set fields from templates. Rules can read other entries (`related`, `count`, `sum`, `unique`, `member`, `covers`), compare against `$NOW` and `$TODAY`, and call an `IRuleLookup` a module registers. See `docs/rules.md`. `BarakoCMS.Abstractions` gains `RuleDefinition`, `RuleCondition`, `RuleWhen`, `IRuleEngine` and `IRuleLookup`.
