- **The constructor overloads that forwarded with a default are gone from eight services.** Each now has one public constructor, and the dependencies a host does not always register default to null on it. Call the one named after each signature:
  - `ContentWriter(session, policy)`, `(session, policy, configuration)` and `(session, policy, configuration, batch)`: call `ContentWriter(session, policy, configuration, batch = null, logger = null)`. The kept `logger` parameter is now nullable.
  - `ContentValidatorService(session)` and `(session, files)`: call `ContentValidatorService(session, files = null, dataSources = null)`.
  - `OtpService(session, email, config, logger)`: call `OtpService(session, email, config, logger, mail = null)`.
  - `TemplateVariableExtractor(session)`: call `TemplateVariableExtractor(session, permissions, sensitivity, configuration)`, passing null for what you do not have.
  - `WorkflowSchemaValidator(pluginRegistry, session)` and `(pluginRegistry, session, configuration)`: the host builds it. The only constructor left is internal, so resolve `IWorkflowSchemaValidator` instead of constructing it.
  - `TenantSessionFactory(store, tenant)`: call `TenantSessionFactory(store, tenant, batch = null)`.
  - `TenantDomainMap(entries)` and `(entries, activeSlugs)`: call `TenantDomainMap(entries, activeSlugs, paused)`, passing `[]` for what you do not have.
  - `SmtpEmailService(options, settings)`, `(options, settings, logger)` and the public four-argument form: call `SmtpEmailService(options, settings, logger = null, tenantSettings = null)`. `BarakoCMS.Email.Smtp` goes to 5.0.0 for this removal.
