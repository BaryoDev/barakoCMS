- **Facebook goes live without App Review, a server-side frontend can finish a social sign-in with a code, and Facebook's data deletion request is answered.** The Facebook start route now asks for `email,public_profile` only; birthday and location are asked for only when `Facebook:RequestBirthdayAndLocation` is `true` (default `false`). With `ExternalAuth:CodeHandoff` set to `true`, every provider callback and the MFA case redirect to `/auth/social?code=...` and the new anonymous `POST /api/auth/social/exchange` returns the token pair or the MFA challenge. A code lasts 60 seconds, works once, and only for the browser that started the sign-in. The default redirect with tokens in the fragment does not change. `POST /api/auth/facebook/data-deletion` checks `signed_request`, removes that person's Facebook link and returns the confirmation code and status URL, and `GET /api/auth/facebook/data-deletion/status/{code}` reports it. New tables `social_handoff_codes` and `facebook_deletion_requests` in `migrations/5.5.0/1270-external-auth-social-handoff.sql`. Setup steps are in `docs/social-sign-in.md`.
