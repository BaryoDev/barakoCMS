- **Build triggers.** The new `BuildHook` workflow action fires a static build once per burst of publishes. Presets: `netlify`, `vercel`, `cloudflare-pages` and `github-dispatch`. The first publish in a quiet period (`QuietSeconds`, default 60) schedules the build, later ones do nothing, and a sweep posts the hook once. The post goes through the webhook path, so a failure shows in `WebhookDeliveries`. `PendingBuild` is a new document. See `docs/build-triggers.md`.
