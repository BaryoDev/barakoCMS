- **A module can declare default content rights for the types it seeds.** `IBarakoModule.ContentPermissions` (a default member, so existing modules compile) takes a `ContentPermissionDefaults`, and the host applies it after the module's `SeedAsync`. A role gets the declared actions only if it has no permission entry for that type yet, so a restart is not a write and rights an admin changed are never overwritten. A module that declares nothing behaves as before.
