- **A failed email or SMS send, or a taken-over workflow attempt, could send a second message.** A send failure other than `EmailNotSentException`, and any SMS provider failure, is now recorded as `Unknown` and not retried. A takeover of an attempt whose lease ran out counts as an attempt, so an action that keeps stopping its node ends at the limit of five. An action that cannot absorb a second run with the same idempotency key, such as Email and SMS, ends as `Unknown` on takeover instead of running again. `IWorkflowAction.HonoursIdempotencyKey` (default false) names the actions that can be run again.
