- **A token refresh no longer uses up the sign-in limit.** Refresh has its own limit, `RateLimiting:Refresh` (60 per 15 minutes per IP by default), so reloading the console does not lock out sign-in. Login, OTP and MFA keep `RateLimiting:Auth`, which no longer governs refresh. A refresh with no cookie is still counted. `refresh` is now a built-in policy name, so a custom policy already named `refresh` fails startup: rename it.
