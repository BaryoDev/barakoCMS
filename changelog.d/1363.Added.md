- **A module can use the branch scope check.** `IBranchScopeGuard` and `BranchScopeFilter` are public, so a module installed from NuGet can narrow branch scoped content to the caller's branches with `FilterAsync` and `MatchesSql`, as core's own routes do. The filter's SQL is a condition for `MatchesSql` over the content table and nothing else. See `docs/your-first-module.md`.
