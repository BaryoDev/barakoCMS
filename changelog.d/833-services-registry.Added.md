- **A registry of outside services.** New package `BarakoCMS.Services`: `POST /api/services` registers a service (name, message types, delivery URL or topic, optional health URL), `GET /api/services` and `GET /api/services/{name}` read it with a health of Healthy, Late or Down, and `POST /api/services/{name}/heartbeat` records that it is alive. Gated by the new `manage_services` and `send_service_heartbeat` capabilities, both given to Admin. Message state, replay and pause come later. Adds the Services tag to the HTTP surface; no existing route changes.
