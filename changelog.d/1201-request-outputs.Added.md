- **A Request step can keep named values from the response as outputs.** A request definition takes optional `outputs` (a name and a plain JSON path each, such as `$.choices[0].message.content`), `missingOutput` (`Fail`, the default, or `Empty`) and `maxOutputLength` (up to 2000). The step returns those values on success, and a later step reads the ones the workflow captures as `{{actions.N.name}}`. Only the named paths are read, never the whole body or a header. A missing path (under `Fail`), a value over the cap, a response that is not JSON or over 256 KiB, or a value that repeats a credential the request sent fails the step and is not retried. A value that holds `{{...}}` is kept as that text.
