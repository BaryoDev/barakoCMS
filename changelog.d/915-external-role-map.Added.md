- **A tenant can map an identity provider claim to roles.** `PUT /api/tenants/external-role-map` takes a claim name (for example `groups`) and rules from a claim value to a role in that tenant, with `GET` and `DELETE` beside it. When someone signs in through an OpenID Connect provider for that tenant, each rule their token matches adds its role to their membership, creating the membership if they have none. It only adds, never touches a removed or suspended member, and refuses SuperAdmin, platform roles and other tenants' roles. Sign-in already finds a returning person by issuer and subject, so a changed email keeps the same account. `BarakoCMS.ExternalAuth` is 4.7.0 and adds the `external_role_maps` table (`migrations/5.1.0/915-external-auth-role-maps.sql`). `GET /api/tenants/members/{userId}/external-identities` lists a member's provider links and `DELETE .../{id}` removes one, for a tenant administrator, members of that tenant only. Per-tenant provider configuration is still open on #915.
