- **The published image kept running with no connection string or no JWT key.** Both throw inside
  `AddBarakoCMS`, which neither host called inside its top-level handler, so the exception reached
  the runtime and it aborted. In a container the host is PID 1, which the kernel does not kill with
  that signal, so `ghcr.io/baryodev/barako-cms` logged the error and spun at full CPU instead of
  exiting. The Suite host (the image entrypoint) and the core host now handle it, log it as fatal,
  and exit 1 within seconds with the missing setting named.
