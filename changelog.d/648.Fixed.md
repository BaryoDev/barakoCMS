- **Malformed or boundary input returned 500 instead of 4xx.** A page number near `int.MaxValue`
  on `/api/audit`, `/api/users`, `/api/files` or `/api/roles` overflowed into a negative OFFSET;
  `Page` is now clamped the way `PageSize` already was, so the request returns an empty page. A NUL
  character in a registration username or email is a validation error, and a NUL that reaches
  Postgres anywhere else (SQLSTATE 22P05 or 22021) is 400. A body over
  `RequestLimits:MaxBodyBytes` is 413 and a multipart body the form reader cannot parse is 400,
  neither echoing the server's own message. A money or decimal value of `1e400` no longer passes
  validation as Infinity and then fails to store. Each of these was a 500 before, so no request
  that used to succeed is refused now, and `ApiContract.Version` does not move (#648).
