- **A fresh start of the production compose file no longer fails at Caddy with "Address already in use".** The app started first and Docker gave it the lowest free address on the `proxy` network, which is Caddy's fixed address. The app now gets its automatic address from the new `PROXY_IP_RANGE` (default `10.87.51.8/29`), which leaves Caddy's address alone. If you set `PROXY_SUBNET` yourself, `PROXY_IP_RANGE` falls back to that subnet, as before; set it to a part of your subnet that leaves `PROXY_ADDRESS` out. The next `up -d` recreates the `proxy` network once to add the range.
