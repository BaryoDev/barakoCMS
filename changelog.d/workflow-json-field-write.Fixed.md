- **A workflow can fill a json field from a template.** `UpdateField` and `CreateContent` stored the text of `{{data.X | json}}` as a string in a field that holds a list or an object. For a json, object or array field they now store the parsed list or object, and fail the action when the text is not a JSON array or object. A whole list or object in a placeholder with no format is now its JSON, not its type name.
