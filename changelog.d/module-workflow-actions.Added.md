- **Modules can add workflow action types.** `IBarakoModule.ConfigureWorkflowActions(IModuleWorkflowActions actions)` registers an `IWorkflowAction` under a type that starts with the module's name and a dot, such as `Sample.PostItem`. A type outside that prefix, one core owns or one another module added stops the host at startup with an error naming the module and the type. The action catalog lists module actions with the metadata of the class the module wrote, and a workflow can be saved with them. `BarakoCMS.Abstractions` is 5.1.0.
