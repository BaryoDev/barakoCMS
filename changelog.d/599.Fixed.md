- **A workflow run could not say whether a failure was permanent, and retrying one left no record
  that it was.** The runner mapped a retryable failure and a permanent one (a malformed URL, an
  unknown action type, a Conditional whose earlier child already went out) to the same `Failed`.
  Each attempt now records `retryable`: `false` for a permanent failure, `true` for a transient one
  that ran out of retries, and `null` for any other status or a failure recorded before this.
  `GET /api/workflow-runs` and `GET /api/workflow-runs/{id}` return it. Retrying a permanent failure
  is still allowed, the way retrying an `Unknown` is, and the `workflow.action.retried` audit entry
  now carries `wasPermanent` next to `wasUnknown`. (#599)
