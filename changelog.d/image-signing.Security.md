- **Released images are signed and carry build provenance.** The release workflow signs `barako-cms` and `barako-cms-decaf` with cosign (keyless, GitHub OIDC) by digest, attaches a provenance attestation, and fails if either does not verify against the `release.yml` identity on `master`. `:latest` now moves only after the platform check, signature and provenance pass. The `:master` and `:master-<sha>` images are signed and attested by their own workflow. `scripts/verify-image-signature.sh <image>` checks an image before you run it, and `docs/deploy-in-production.md` lists what is and is not signed. Images published before this change are not signed.
