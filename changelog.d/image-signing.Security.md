- **Released images are signed and carry build provenance.** The release workflow signs `barako-cms` and `barako-cms-decaf` with cosign (keyless, GitHub OIDC) by digest, after the platform check, and attaches a provenance attestation. The release fails if a signature does not verify against the release workflow identity. The `:master` image is signed by its own workflow. `scripts/verify-image-signature.sh <image>` checks an image before you run it, and `docs/deploy-in-production.md` has the commands. Images published before this change are not signed.
