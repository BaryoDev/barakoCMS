- **Troubleshooting page.** `docs/troubleshooting.md` has one entry for each refusal at start: the exact message, why it happens and the fix. It covers the startup guards under `barakoCMS/Infrastructure/Security/`, the request limit checks, the module contract refusal, the `${VAR:?message}` text in each compose file, a 400 from `AllowedHosts`, a port already in use and a certificate requested before DNS resolves. `TroubleshootingPageTests` reads each quoted message and finds it in the source it names, so a changed message fails the test, and fails when a guard class that can stop a start is not named on the page. The page is linked from the quickstart and the production deploy guide.
