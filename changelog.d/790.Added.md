- **Resolving a client error can say what fixed it.** `POST /api/client-errors/{id}/resolve` accepts an
  optional `reference` (a pull request or ticket link, or a number such as `AB#1234` or `PROJ-42`, up
  to 500 characters) and `note` (up to 2,000). Both are stored with the resolving user's name, and
  `GET /api/client-errors` returns `resolvedAt`, `resolvedBy`, `resolutionReference` and
  `resolutionNote`. Reopening clears them. Additive on the request and the response, so a resolve
  with an empty body behaves as before and `ApiContract.Version` does not move. BarakoCMS.Diagnostics
  4.1.1 (#790).
