- **Taking a published entry down, or erasing one, fired no workflow.** A status change away from
  Published now fires the `Unpublished` trigger, and `DELETE /api/contents/{id}/erase` fires
  `Deleted`. A `Deleted` run carries the entry's id and content type and none of its data, so a
  `Deleted` workflow with conditions does not fire. A workflow can also name several events in
  `triggerEvents`, beside `triggerEvent`, the way `triggerContentTypes` sits beside
  `triggerContentType`; an event fires it once however many entries match. Both fields are optional
  and a workflow stored without them fires as before, so `ApiContract.Version` does not move (#663,
  #664).
