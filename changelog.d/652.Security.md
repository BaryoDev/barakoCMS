- **The OAuth `state` for Google, GitHub, Facebook and LinkedIn sign-in came from `Guid.NewGuid`.**
  Every other secret the API mints uses `RandomNumberGenerator`, and a GUID does not promise to be
  unpredictable. The state is now 32 bytes from `RandomNumberGenerator`, base64url encoded. This was
  not exploitable, since the callback also checks the state against an HttpOnly, Secure, SameSite
  cookie, but that check should not be the only thing standing between a guessable value and a
  login CSRF. `BarakoCMS.ExternalAuth` goes to 4.1.1 so the change is published. (#652)
