- **One renderer serving many sites shared one rate limit bucket of 100 a minute.** Every limit is
  now configuration: `RateLimiting:Global`, `Auth`, `Batch` and `Registration`, each with
  `PermitLimit`, `WindowSeconds` and `QueueLimit`, defaulting to the old hard coded values. An invalid
  value stops the host at startup, and loosening `Auth` or `Registration` logs a warning. Setting
  `RateLimiting:Renderer:Key` (at least 32 characters) gives requests carrying it in the
  `X-Barako-Renderer-Key` header their own global bucket, sized by `RateLimiting:Renderer:PermitLimit`
  and `WindowSeconds`. A wrong key counts against the IP, and the auth, batch and registration limits
  ignore the key. No routes or response shapes change, so `ApiContract.Version` does not move. (#823)
