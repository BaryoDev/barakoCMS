- **A redirect target starting with a backslash was stored verbatim, so a frontend following it
  left the site.** `UrlRedirect.Normalize` collapsed `//` but left `\evil.com` alone, and a browser
  reads a backslash as a slash, which makes that a protocol-relative link to another host. A tab or
  newline between the slashes did the same, since a browser drops them before parsing. Normalize
  now removes control characters and turns backslashes into slashes before collapsing, so both
  store as `/evil.com`. Stored rules are not rewritten: a target saved with a backslash keeps it
  until the rule is saved again, and a from path saved with one stops matching, because lookups
  are normalised the same way. (#649)
