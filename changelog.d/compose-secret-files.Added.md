- **Secrets can be files.** The API reads `BARAKO_SECRETS_DIR` (default `/run/secrets`) as configuration, one file per key with `__` as the section separator, and a file wins over an environment value. `docker-compose.secrets.yml` keeps the JWT key, admin password and database password in `./secrets/`. Caddy no longer sends `Server` or `Via` headers on proxied responses and the site's own errors. See "Secrets as files" in `docs/deploy-in-production.md`.
