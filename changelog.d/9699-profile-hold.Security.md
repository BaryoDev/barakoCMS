- **A members manager could widen a member's roles by editing their profile.** Setting `branches`, or any attribute a role's rule condition reads, can let a role the member already holds allow rights the caller never held. Adding a member with a profile and updating one now refuse with a 403 unless the caller holds the value being set (each added branch for `branches`, the same value for any other attribute). A SuperAdmin and the tenant's Admin still pass.
