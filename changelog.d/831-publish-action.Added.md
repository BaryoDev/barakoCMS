- **A workflow can publish to an outside service.** The new `Publish` action takes `Url`, `Topic`, `MessageType`, `Payload` and an optional `Secret`. `Payload` is a JSON object of text values, and only what it names is sent: placeholders are limited to `id`, `contentType`, `status`, `createdAt`, `updatedAt` and `data.<Field>`, and a field that is not Public is refused when the workflow is saved. The action writes an `OutboxMessage` in the same save that records the run, so the run succeeds once the message is stored and a rolled-back attempt leaves none. A background sender posts it signed like a webhook (`X-Barako-Signature`, with the message id as `X-Barako-Delivery` and `Idempotency-Key`), retries with backoff from 30 seconds up to an hour, dead-letters after `Outbox:MaxAttempts` (10) or a 4xx refusal, and writes each send to the webhook delivery log. `OutboxMessage` and `OutboxStatus` are new public models.
