- **A workflow can fire on a schedule.** Set the trigger event to `Schedule` and give a 5-field cron expression in `schedule`, read in `scheduleTimeZone` (`tenant` for the site time zone, or an IANA id such as `Asia/Manila`). Saving returns the next five due times as `nextDueTimes`. One run is queued per due time however many hosts run, and a host that was stopped over several due times queues one run for the latest. The run reads `{{schedule.at}}` and `{{schedule.previousAt}}`.
