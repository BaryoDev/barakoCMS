- **A fresh start of the production compose file no longer fails at Caddy with "Address already in use".** The app starts before Caddy and Docker gives it the lowest free address on the `proxy` network, which was Caddy's fixed address, `10.87.51.2`. The default `PROXY_ADDRESS` is now `10.87.51.14`, the last address of the subnet, and the next `up -d` recreates `caddy` and `app` with it. The network itself does not change. If you set `PROXY_ADDRESS` yourself, move it to the last usable address of your `PROXY_SUBNET` (`.14` in a `/28`).
