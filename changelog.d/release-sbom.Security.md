- **Released images now carry the CycloneDX SBOM as a signed attestation, and the GitHub release has the SBOM file attached.** The image job attests it to `barako-cms` and `barako-cms-decaf` and verifies it against the `release.yml` identity. If that fails, `:latest` does not move and no GitHub release is written. The NuGet packages go out in an earlier job and are not held back by it. The SBOM now leaves test projects out, so test-only packages no longer appear in it. `scripts/verify-image-signature.sh` checks it for release images, and `SECURITY.md` says how to verify an image.
