- **Google, Facebook, GitHub and LinkedIn sign-in follow the provider's account id, not the email.** A person whose address changes at the provider now signs in to the same local account. A tenant's claim-to-role map applies on these providers too, as `oauth:google` and so on. No HTTP shape changes. ExternalAuth 4.9.0.
