- **A workflow can fill a json field from a template in `Transition` and `CreateTask`, and a json field only takes a whole list or object.** `Data.<Field>` values such as `{{data.BilledLines}}` reached a json, object or array field as text, so a `Transition` failed with "expects type 'json' but received 'string'" and `CreateTask` stored the text. Now, for `Transition`, `CreateTask`, `UpdateField` and `CreateContent`, a json, object or array field is filled only when the parameter is exactly one `{{data.X}}` or `{{data.X | json}}` placeholder whose field holds a list or an object. A template that mixes JSON with a placeholder, such as `{"note":"{{data.Name}}"}`, or a text field that holds JSON, is refused with a permanent failure that names the field, so a typed value cannot add keys.
