- **Saving or previewing a template that links a transition the type does not declare now warns.** A `links.transition` or `links.action` naming a transition the content type does not declare, such as a misspelt name, is listed in the `warnings` of the email template preview and of a workflow save that names the template or holds the text itself. The save is not refused. A rollback keeps the entry's lifecycle state, so it needs no guard for a state the type no longer declares.
