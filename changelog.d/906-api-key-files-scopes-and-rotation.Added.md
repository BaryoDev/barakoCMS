- **API keys can reach files, and can be rotated with an overlap window.** New scopes `files:read` and `files:write` cover `/api/files`. `POST /api/api-keys/{id}/rotate` issues a replacement key and keeps the old one valid for `overlapMinutes` (default 60, at most 10080). A `*` key now reaches `/api/files` too, as its owner. Service principals are still to do, see `docs/api-key-service-principals.md`.
