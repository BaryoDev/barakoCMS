- **A new module renders an entry to a PDF.** `BarakoCMS.Documents` adds the `RenderDocument` workflow action (`{ "Type": "RenderDocument", "Parameters": { "Template": "invoice" } }`), which draws the entry with SkiaSharp from a narrow template language (titles, headings, paragraphs, rules and table rows with `{{field}}` holes) and stores the PDF through the Files module. The renderer only draws text, so a template cannot fetch anything. A template naming a field that is not Public is refused, using the same check as outbound requests, and two runs with the same idempotency key store one file. There is no template endpoint yet.
