- **The API contract moves from 16 to 17.** A name, slug, handle, locale, email or similar value that ends with a line feed is now refused where it used to be accepted. The ExternalAuth module's contract moves from 1 to 2 and the Files module's from 2 to 3 for the same reason. Config apply and blueprint apply now refuse a type whose lines do not hold, where they used to store it with the lines dropped, and the Portability module's contract moves from 2 to 3 because an import refuses the same. Deploy barakoBrew 1.14.0, which accepts 17, before or with this release.
- **A saved query or request definition whose slug ends with a line feed can no longer be opened by that slug.** Rename or remove it before upgrading. An entry whose slug or email field holds such a value keeps it on an edit that sends it back unchanged.
