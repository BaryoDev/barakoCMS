- **A Members audience between Public and staff, and a viewer token for delivery.** Entries and fields can be marked `Members`. `GET /api/public/{type}` and `GET /api/public/{type}/{slug}` serve them when the request carries an `X-Viewer-Token` header, minted with `POST /api/viewer-tokens` (needs `manage_public_delivery`). Without the header delivery answers exactly as before. A token that does not verify for the tenant is a 401, a response built for a viewer is `private, no-store`, and a viewer token opens no authoring route. Delivery contract: additive (a new enum value and a new optional header). See [Members and viewer tokens](docs/delivery-api.md#members-and-viewer-tokens).
