- **An Email step can attach a file an earlier step of the same run produced.** Set `Attachments` to `{{actions.N.name}}`, where step N captures an output holding the file id and declares the file in `WorkflowActionResult.ProducedFiles`. The file may be private, because the run made it. An id typed into a field or a parameter is still refused unless it is public and the entry names it, and the existing count and size limits apply. `IFileStore` gains `FindForRunAsync` and `OpenForRunAsync` (default implementations throw `NotSupportedException`), `WorkflowContext` gains `ProducedFiles`.
