- **A locked account answered 423, which told anyone whether a username existed.** An account that
  does not exist never locks, so six wrong passwords separated real usernames from invented ones, and
  the stated minutes said how often to re-lock one. A locked account now answers
  `401 "Invalid credentials"`, the same status and body as a wrong password or an unknown username,
  even when the password is right. The owner is emailed when the lock is set instead, whether five
  wrong passwords or five wrong MFA codes set it. The notice goes out once per lock, however many
  requests cross the threshold together, and it is sent after the response, so the attempt that
  locks an account does not wait on the mail provider. Setting a lock now resets the failure count,
  so an expired lock takes five more failures to set again rather than one. See the Breaking entry
  for the contract version. (#640)
