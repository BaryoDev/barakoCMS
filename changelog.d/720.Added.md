- **A public visitor had no way to submit a form.** The new `BarakoCMS.Forms` module (4.2.0) turns a
  content type into a form with `PUT /api/forms/{contentType}`. `POST /api/public/forms/{slug}`
  then takes anonymous submissions validated against that type's Public fields, refuses unknown
  fields, and stores each one as a Draft entry with document sensitivity Sensitive and no owner, so
  delivery never serves it back. Submissions are rate limited per client IP, a filled honeypot is
  answered like a success and dropped, and Cloudflare Turnstile can be required through
  `Modules:Forms:Turnstile`, off by default. `GET /api/public/forms/{slug}` returns the fields a
  widget draws. Entries go through `IContentWriter`, so a workflow on Created sends the
  notification. New routes only, so `ApiContract.Version` does not move (#720).
