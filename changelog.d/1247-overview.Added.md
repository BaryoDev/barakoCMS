`GET /api/overview` returns the rule-based "Today at a glance": counts with a prior period, a Needs you list, and a health strip with a verdict, each part left null for a caller without the capability behind it. `POST /api/overview/items/{id}/resolve` clears the bounces item. A `monitor:read` key can read the overview, and an email module can report bounces through the new `IMailBounceSource`.
