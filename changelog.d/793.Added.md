- **A `site` blueprint for a site's identity, theme and chrome.** `POST /api/content-types/blueprints/site`
  creates one publicly deliverable singleton type per tenant: name, tagline, address, locale, logos,
  favicon and share image as plain fields, and colours, fonts, radii, widths, colours per option,
  visitor theme variants, top bar, header links, footer columns and social links as JSON. A renderer
  reads it from `GET /api/public/site`, so a site's look is content edited in barakoBrew instead of a
  file in the site's repository. The JSON shapes are in `docs/site-settings.md`. No new endpoint and
  no contract change (#793).
