- **Retention sweeps share one primitive.** Workflow run retention, webhook delivery retention and the expiry pass in token cleanup now declare what they keep and for how long, and one sweeper does the advisory lock, the tenant walk, the delete and the log. Windows, config keys and per-tenant behaviour are unchanged. Webhook delivery retention now takes an advisory lock too, so two nodes no longer sweep the same rows. Partitioning the run and delivery tables is not part of this change.
