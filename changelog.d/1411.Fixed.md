- **MFA challenge, step-up, preview and viewer tokens now validate when `JWT:Key` holds a character outside ASCII.** Minting and bearer validation always read the key as ASCII bytes, but those four validators read it as UTF8, so on such a site every one of those tokens failed while access tokens worked. They all take the key bytes from `JwtKeySource.Bytes` now. No access token changes. Startup logs a warning for a non-ASCII key and does not refuse it.
