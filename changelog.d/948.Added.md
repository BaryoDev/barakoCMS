- **A content lifecycle hook can take a lock, load and store documents without naming a Marten type.** `IContentHookContext` gains `LockAsync(key, ct)`, `LoadAsync<T>(id, ct)` and `Store<T>(document)`. The lock is a transaction-scoped lock on the key and the tenant of the write, held until the write commits or rolls back. A stored document commits with the content write and is gone if the write fails. `IContentReader` gains `GetContentTypeAsync(name, ct)`. All are default interface members, so an outside implementer still compiles. `PageTreeHook` in BarakoCMS.Pages moves onto them and no longer uses the obsolete `context.Session`, and that project now builds with CS0618 as an error. The module template keeps its notes as ordinary content entries, so a generated module has no `using Marten`. The Marten-typed members stay obsolete until 6.0.0.
