A tenant can override settings that modules declare. Modules list sections in `IBarakoModule.SettingsSections` (keys, categories, descriptions, secret or host-only flags), and `GET` and `PUT /api/tenant-settings/{section}` read and write one tenant's values in a single tenant settings document. An unknown section is 404 and an unknown key is 400. Secrets are stored encrypted and never returned. A resolver reads the tenant override, then the stored host default, then configuration. SMTP business mail (`SendForTenantAsync`) uses the tenant's `Email.Smtp` From, and account mail keeps the host sender. `Files.S3` and `AI` declare sections, with no runtime use of the overrides yet. The module configuration endpoint shows a tenant caller its own override for tenant-scoped keys (#896, #890).
