- **Creating a user group now checks that every listed user belongs to the caller's tenant.** `POST /api/user-groups` answers 404 and stores nothing when a user id is unknown or outside the tenant, as adding a user to an existing group already does. A request that listed such an id used to be accepted. This is a breaking change to the admin HTTP contract, carried by the move to 14 in `admin-contract-14.Breaking.md`.
