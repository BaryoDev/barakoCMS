- **A tenant's domains are set through the API, and a host can be looked up.** `POST /api/tenants`
  and `PUT /api/tenants/{handle}` accept `domains`, bare hosts such as `example.com`, stored the way
  requests are matched (lower case, no `www.`, no trailing dot). A value with a scheme, port, path
  or wildcard is a 400, a domain another tenant holds is a 409 naming that tenant, and a tenant holds
  at most 20. On update, leaving `domains` out keeps them and an empty list clears them, so a client
  that does not send the field changes nothing. Every tenant write clears the cached domain map, so
  a change routes on the next request instead of after `Multitenancy:CacheDuration`. New
  `GET /api/tenants/by-host/{host}`, anonymous, answers `{ "handle": ... }` for an active tenant's
  domain and 404 otherwise, so one renderer can serve several sites. Additive, so
  `ApiContract.Version` does not move (#792).
