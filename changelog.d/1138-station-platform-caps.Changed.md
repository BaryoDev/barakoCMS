- **A station key can no longer hold a platform capability.** `POST /api/stations` answers 400, naming the capability, when the request lists `manage_tenants`, `manage_roles`, `manage_platform_roles`, `manage_users`, `manage_email_settings` or `view_hidden`, the same set member role grants already refuse. Before, a caller who held one could put it on a station key. Station keys already created with one are not touched: list them with `GET /api/stations`, revoke them and issue new ones. Admin contract moves to 9: a create request that was accepted is now rejected.
