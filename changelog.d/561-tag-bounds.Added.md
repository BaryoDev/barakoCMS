- **Raise the cache tag bounds.** `Delivery:CacheTags:MaxTags` (default 32, allowed 1 to 1000) and `Delivery:CacheTags:MaxHeaderLength` (default 1024 bytes, allowed 1024 to 16384) let a list response tag every entry it contains. A deployment that sets nothing sends the same headers as before. A value outside the range is clamped and logged as a warning at start. `Surrogate-Key` and `Cache-Tag` carry the same value, so a raised length costs twice its size in response headers, and a proxy that accepts less breaks the response: raise nginx `proxy_buffer_size` to match. The ceiling is the 16 KB header limit of Cloudflare `Cache-Tag` and Fastly `Surrogate-Key`. `DeliveryCache.TagHeaderValue` has an overload that takes the bounds (#561).
