- **Modules are found by an assembly attribute, and a module can build on the contract package alone.** `[assembly: BarakoModuleAssembly]` (namespace `barakoCMS.Modules`, in `BarakoCMS.Abstractions`) marks a library that references only the contract. One without it is still scanned in 5.9.0 and logs one startup warning naming it; 6.0.0 stops scanning it. A library that reaches `BarakoCMS` is scanned as before. Every first-party module and the module template carry the attribute. `BarakoCMS.Email.Smtp` no longer references `BarakoCMS`, so its lock file lists 62 packages instead of 149. `IPublicBaseUrl` (contract, implemented in core) answers the deployment's public base URL, and ExternalAuth uses it instead of `CanonicalHost`. `IMfaService` gains `CreateChallengeToken`, which ExternalAuth uses instead of core's `MfaChallengeToken`. It is a default interface member that throws `NotSupportedException`, so an `IMfaService` implemented outside core still compiles and loads, but cannot start a second-factor challenge until it overrides the member. Core's own implementation does.
