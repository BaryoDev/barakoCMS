- **Workflow runs can be traced to what they created.** An action reports the entries it created with `CreatedRef`, kept on its attempt. An entry created by a run carries `Content.SourceRunId`. `GET /api/contents/{id}/runs` lists the runs of an entry, and with `includeCreated=true` the runs that created it. A module can fire a trigger with a key (`WorkflowRun.TriggerKey`) so a retry queues one run. `WorkflowDefinition.NotifyRoleOnFailure` names a role to tell about failures. See `docs/workflow-runs.md`.
