- **Deleting an account content type lists the API keys that name it.** `DELETE /api/accounts/{slug}/content-types/{name}` still deletes, and now answers 200 with `apiKeyWarnings` (key id, name, prefix and the matching types) when live keys of the caller's tenant name the type, since those keys can no longer push to it. It answers 204 as before when no key names it. Revoked and expired keys are not listed. See `docs/api-key-service-principals.md`.
