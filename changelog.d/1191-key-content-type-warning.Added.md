- **A dry run of an account content type delete counts the API keys that name the type.** `DELETE /api/accounts/{slug}/content-types/{name}?dryRun=true` runs the same checks as the delete, deletes nothing, and answers 200 with `dryRun`, `apiKeysAffected` (live keys of the caller's tenant that name the type; revoked and expired keys are not counted) and `apiKeyWarnings` (key id, name, prefix and matching types). The warnings are filled only for a caller who may manage API keys, and are empty for one who holds only ManageTenants. The delete itself answers 204 as before. See `docs/api-key-service-principals.md`.
