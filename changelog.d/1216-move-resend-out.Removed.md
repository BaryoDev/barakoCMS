The Resend email module, `BarakoCMS.Email.Resend`, is no longer built from this repository, and the core and the Suite no longer read `Resend:ApiKey`, `Resend:From` or `RESEND_API_KEY`. Versions already published keep working. A host that uses Resend adds `BarakoCMS.Email.Resend` from the BarakoCMS.Pro feed, or switches to `BarakoCMS.Email.Smtp`. The core now reads a provider-neutral `Email:ApiKey`, `Email:From` and `EMAIL_API_KEY`, and the stored email settings are unchanged. The `POST /api/webhooks/resend` and `GET /api/email-events` routes belong to that module and are gone from the Suite. `ApiContract.Version` moves to 11 for the two removed routes; the Settings, Email request and response are unchanged. The settings test send no longer needs an API key, so it works with SMTP (#1216).
