- **The Resend email module moved to the private feed.** `BarakoCMS.Email.Resend` is no longer built from this repository, and the core and the Suite no longer read `Resend:ApiKey`, `Resend:From` or `RESEND_API_KEY`. This breaks a host that set any of them. Move to `Email:ApiKey`, `Email:From` or `EMAIL_API_KEY`, or install the private Resend module from the BarakoCMS.Pro feed and set `Email:ApiKey` (or the key in the admin email settings) for it, since it takes its key from the core settings and does not read `Resend:*`. Or switch to `BarakoCMS.Email.Smtp`. The stored email settings are unchanged. The `POST /api/webhooks/resend` and `GET /api/email-events` routes belonged to that module and are gone from the Suite. `ApiContract.Version` moves to 11 for the two removed routes; the Settings, Email request and response are unchanged. The settings test send no longer needs an API key, so it works with SMTP and no longer returns 400 for a missing one. A host that still sets `Resend:ApiKey` or `RESEND_API_KEY` gets a startup warning when email falls back to the mock (#1216).
