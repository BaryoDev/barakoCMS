- **The durable work seams are in the package contract, with nothing behind them yet.**
  `BarakoCMS.Abstractions` 4.6.0 adds `IDurableOutbox` (queue a message, or schedule one for a
  time, in the caller's own transaction), `IDurableRuns` (start a run once per id, park it until a
  key is resumed or a deadline passes, resume it) and `IDurableMessageHandler<TMessage>` with
  `DurableMessageContext` (a plain class that handles one message type and is told the tenant and
  the message's id). Every call names its tenant. No signature names a Marten, Wolverine,
  FastEndpoints or ASP.NET type. The host registers no implementation and nothing in the core calls
  them: resolving one fails until the implementation lands in #965 (#964).
